# Mã nguồn

- `xu_ly_du_lieu/`: đã có script tải, chuẩn hóa và kiểm tra dữ liệu.
- `giaodien/`: giữ chỗ cho một file chính Streamlit `app.py`.
- `backend/`: giữ chỗ cho một file chính `backend.py` xử lý SQLite, phân loại, truy xuất và LLM.
- `train/`: giữ chỗ cho mã huấn luyện và đánh giá năm mô hình.
- `.data-tools/`: thư viện hỗ trợ local, không phải dữ liệu; Git bỏ qua thư mục này.

Chỉ script dữ liệu đã có; chưa có ứng dụng web hoặc chương trình train. Xem [kiến trúc](../06_tai_lieu/PROJECT.md) trước khi triển khai.
